CommonSpace

Find and hold a desk in cafes, libraries and coworking spaces. A coaster on every table shows whether it is free; every search and booking feeds demand insights that tell each space which add-on to trial.

Every page below runs the real Python backend inside your browser (Pyodide), seeded with six Pittsburgh spaces and six weeks of history. Nothing is shared between visitors and data resets on reload. The same code runs as a normal server with python3 server.py.

Worker app

Pre-book flow: find a space, rules, pick a table, phone, confirm, arrive, check in, locker, session, away, wrap up.

Walk-in (table mat QR)

No app, no booking: scan the mat, see free-until, hold with a phone number, SMS when a booking is coming.

Floor overview display

Entrance and elevator screen: open desks, booked soon, scan to hold.

Room display

Replaces the whiteboard on each pod and room.

Provider

Dashboard, tag bookable zones, set rules and publish, staff desk hand-off and coaster return.

Coaster wall

Every coaster's light and countdown; tap or hold as any user.
